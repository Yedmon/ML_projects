# Machine Learning Projects

A collection of machine learning implementations, experiments, and mini-projects built while studying machine learning.

This repository documents my learning journey—from implementing fundamental algorithms from scratch to building practical machine learning pipelines.

The primary goals of this repository are to:

* Strengthen my understanding of machine learning fundamentals
* Practice implementing algorithms and workflows in Python
* Learn industry-standard tools such as Scikit-learn
* Build reproducible machine learning projects
* Serve as a reference for future projects
